# AI Agent Setup

This directory defines repository-specific guidance for AI coding agents.

## Structure

- `.ai/rules/`: mandatory behavior rules.
- `.ai/skills/`: reusable implementation playbooks.

## How to Use

1. Read `.ai/rules/core.md` before making any change.
2. Pick a relevant skill from `.ai/skills/` for the task.
3. Follow `AGENTS.md` and `CLAUDE.md` for repository contracts and validation steps.
