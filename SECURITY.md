# Security Policy

## Supported Versions

This project currently supports security updates for the latest `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

- Do not open a public issue with exploit details.
- Use a private security advisory in GitHub when available.
- Include reproduction steps, impact, and affected versions/commits.

We aim to acknowledge reports within 3 business days and provide a remediation
plan as quickly as possible.

## Secrets and Credentials

- Never commit API keys, tokens, or `.env` files.
- Use placeholder values in docs and examples.
